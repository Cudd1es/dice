# DND Dice 快速上手

[English](quick-start.md) · [完整使用指南](user-guide.zh-CN.md)

从安装到投出第一把骰子，五分钟就够。

## 1. 安装

DND Dice 目前通过 TestFlight 内测。

1. 打开邀请邮件或链接，在 App Store 安装 **TestFlight**，接受邀请。
2. 在 TestFlight 里安装 **DND Dice**。
3. TestFlight 提示有新版本时就更新。群里大家都要用较新的版本，才能互相读懂投骰消息。

## 2. 在 App 里投（线下跑团）

1. 打开 DND Dice。
2. 选骰子（d4–d100），再设好**数量**和**加值**。
3. 点**投掷**。结果大字显示在上方，并记进**最近**。

## 3. 在「信息」里投（线上跑团）

1. 在「信息」里打开一个对话。
2. 点输入框左边的 **+**，选 **DND Dice**。找不到的话，往下滑或点**更多**。
3. 设好骰子后点**投掷**。投骰会作为草稿放进输入框，草稿上只显示公式。
4. 发送后，气泡对群里所有人显示结果。

发送前谁都看不到结果，包括你自己，所以没法重投。

## 4. 试试这些

| 想做什么 | 怎么操作 |
|---|---|
| 对抗 DC 的检定 | 主骰 d20，设好加值，打开 **DC**，点数字直接输入 |
| 优势 / 劣势 | 主骰 1d20，选**优势**或**劣势** |
| 祝福术（+1d4） | 点 **＋ 加成** → **d4** |
| 灾祸术（−1d4） | 点 **＋ 加成** → **减** → **d4** |
| 伤害 `1d8+2d6+3` | 主骰 d8、加值 +3，再 **＋ 加成** → d6 点两次 |
| 写明投骰目的 | 在最上方的目的输入框里写，例如「察觉检定：门后有没有人」 |

每个控件的详细说明见[使用指南](user-guide.zh-CN.md)。
