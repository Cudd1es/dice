# 掷定使用指南

[English](user-guide.md) · [快速上手](quick-start.zh-CN.md)

「掷定」可以帮你做决定：给选择过一次 d20 检定，DC 代表这件事该不该做，加减值和优劣势代表你自己的意愿。它也是跑团用的骰子。有两个地方可以投，用的是同一个面板：

- **App 里：**适合线下跑团，结果显示在你自己的屏幕上，下面列出最近的投骰。
- **「信息」里：**适合线上跑团，投骰作为消息发出，发送前谁都看不到结果。

界面跟随手机语言，支持英文和简体中文。

## 用检定做决定

拿不定主意时，把它当成一次检定：

1. **在目的栏写下问题**，例如"买不买那双 90 刀的鞋？"
2. **用 DC 表示这件事该不该做。**理智上该做的，DC 低一些（5–10）；不太该做的，DC 高一些（15–20）。
3. **用加值表示你有多想做。**加 +1 到 +5；特别想做就开优势，不太想就开劣势。
4. **投 d20。**成功就去做，失败就算了。天然 20 和天然 1 直接决定结果，除非在设置里关掉了大成功判定。

在「信息」里投，朋友也能一起看到结果。

## 投骰面板

从上到下：

| 控件 | 作用 |
|---|---|
| **目的** | 可选，最多 40 字，例如「攻击哥布林」。跟着这次投骰一起显示，投完自动清空。✕ 可以清空。超过 30 字时显示字数，超过 40 字变红；投掷时只保留前 40 字。 |
| **骰子** | d4、d6、d8、d10、d12、d20、d100，这是"主骰"。 |
| **数量** | 主骰个数，1–20。 |
| **加值** | 固定加到总值上的数，−20 到 +20。 |
| **加成标签** | 已加上的加成骰，例如 +1d4，只在加了之后出现。见[加成骰](#加成骰)。 |
| **普通 / 优势 / 劣势** | 只有主骰正好是 1d20 时才能选。 |
| **DC** | 可选的目标值，1–999。可以用 − / + 调，也可以点数字直接输入；点**完成**或直接投掷就会生效。输入框留空时 DC 保持原值。 |
| **＋ 加成** | 在 DC 那一行的最右边，打开加成骰选择。 |
| **公式** | 将要投的内容，例如 `1d20+1d4+5 · 优势 · DC 15`。 |
| **投掷** | 投骰。固定在面板最下方，始终可见。 |

面板会记住上次的公式（骰子、加值、优势、DC）。目的和加成骰只用于这一次投骰，投完就清空。App 和「信息」里的面板各记各的。

### 加成骰

加成骰是在主骰之后额外投的骰子组，加进总值，也可以从总值里减去。常见用法：祝福术、神导术（+1d4），灾祸术（−1d4），或者伤害组合，比如偷袭 `1d8+2d6+3`。

**添加**
1. 点 **＋ 加成**。
2. 选**加**或**减**。
3. 点一个骰子。加上后马上回到面板。

再点同一种会合并，+1d4 点两次就是 +2d4。

**预设**

二级菜单里还有按 2024 年规则（[SRD 5.2.1](https://www.dndbeyond.com/srd)）整理的常用加成，点一下就加上。它们自带加减方向，不受「加 / 减」切换影响。

| 分类 | 预设 | 加上 | 规则 |
|---|---|---|---|
| 检定 | 祝福术 | +1d4 | 攻击检定和豁免检定 |
| 检定 | 神导术 | +1d4 | 用所选技能的属性检定 |
| 检定 | 灾祸术 | −1d4 | 目标的攻击检定和豁免检定 |
| 检定 | 诗人激励 | +d6 / d8 / d10 / d12 | 按吟游诗人等级选：d6，5 级 d8，10 级 d10，15 级 d12 |
| 伤害 | 猎人印记 | +1d6 | 每次命中被标记的目标 |
| 伤害 | 脆弱诅咒 | +1d6 | 每次命中被诅咒的目标 |
| 伤害 | 神恩术 | +1d4 | 武器命中 |
| 伤害 | 至圣斩 | +2d8 | 1 环法术位。更高环位或对邪魔、亡灵时，点 d8 标签的**多一个** |

预设和普通加成骰一样会合并：祝福术加神导术就是 +2d4。

**修改**

点它的小标签（例如 **+2d4**），可以选**多一个**、**少一个**或**删除**。

**上限**
- 最多 4 组，每组 1–10 个，d4 到 d100。
- 满 4 组后，只能加能合并进已有组的骰子。

**规则**
- 优势、劣势和大成功、大失败只看主骰的 d20。开优势时，两个 d20 取高，加成骰全部照常计入。
- 加成骰计入 DC 判定。主骰天然 20 仍然必定成功，天然 1 仍然必定失败（设置中关闭判定时除外）。
- 总值可能是 0 或负数（例如 `1d4-2d6`），按实际结果显示。

## 怎么看结果

| 部分 | 示例 | 含义 |
|---|---|---|
| 总值 | **25** | 大成功显示橙色，大失败显示红色 |
| 明细 | `[~~11~~, 16] + [4] + 5 = 25` | 先是主骰（划掉的是优势或劣势舍弃的那颗），然后依次是各组加成骰，最后是加值 |
| 成败 | **成功** | 主骰 d20 天然 20 / 1 时显示大成功 / 大失败（关闭判定时除外）；否则按 DC 显示成功 / 失败 |

**关闭大成功判定。**如果你们团不用大成功 / 大失败，在 App 里点齿轮打开**设置**，关掉**大成功 / 大失败判定**：
- 关掉后天然 20 / 1 只是普通点数，只用总值和 DC 比较；
- 公式末尾会标出"不判定大成功"，大家都能看出这次用的是哪种规则；
- 这个设置和「信息」里的面板共用；
- 你发出的投骰按你的设置判定，所以不管群里其他人怎么设置，大家看到的结果都一样。

## 在 App 里投

整个屏幕就是投骰界面：
- 上方是最新结果；
- 中间是**最近**：最近 10 次，新的在上，每行有时间、公式、总值、成败和目的；
- 下方是面板。

每次投掷手机会轻震一下，大成功和大失败震得更明显。关掉 App 后**最近**会清空。

右上角的 **?** 是 App 内的使用说明。

## 在「信息」里投

1. 在对话里点输入框左边的 **+**，选 **掷定**。
2. 设好要投的骰子。点目的或 DC 输入框时，面板会展开到全屏，好让键盘弹出来。
3. 点**投掷**。草稿会放进输入框，上面只显示目的、公式和"发送后揭晓"，不会显示结果。
4. 发送后，气泡对所有人显示结果，不用点开。
5. 点已发送的气泡可以查看完整结果，气泡里被"…"截断的目的也能看全（需要 0.6.2 或更新版本）；**再投一次**回到面板。

### 谁能看到什么

| 谁 | 看到什么 |
|---|---|
| 你自己，发送前 | 只有公式，所以重投没有用 |
| 装了「掷定」的人，发送后 | 同一个结果，各自用自己手机的语言显示 |
| 没装「掷定」的人 | 公式和"安装「掷定」查看结果" |
| 用旧版本的人 | 能读懂的消息正常显示；用到新功能的消息显示"无法读取这次投骰，请更新 App"。0.3.0 之前的版本收到 DC 超过 40 的消息会显示"数据无效" |

版本要求：
- 看到投骰目的需要 0.3.0 及以上；
- 读取加成骰需要 0.4.0 及以上；
- 读取关闭了大成功判定的投骰需要 0.6.0 及以上。

## 常见问题

| 问题 | 解决办法 |
|---|---|
| 「信息」里「掷定」的面板是灰色的空白 | 稍等一下，或者上滑关掉「信息」再打开。刚更新完时可能会遇到。 |
| + 列表里找不到「掷定」，或者没有图标 | 重启手机。iOS 会缓存「信息」里的 App 图标。 |
| 气泡显示"无法读取这次投骰，请更新 App" | 在 TestFlight 里更新「掷定」。 |
| 气泡显示"数据无效" | 消息被损坏或修改过；或者是 0.3.0 之前的版本收到了 DC 超过 40 的消息。 |
| 朋友只看到公式和安装提示 | 他们需要安装「掷定」。 |
| 气泡的语言和草稿不一样 | 这是正常的：每台手机用自己的语言绘制气泡。 |

## 公平性

结果在点投掷时就已确定，并且在发送前对所有人隐藏，包括你自己。

不过结果是以明文写在消息里的。它能防止朋友之间随手重投，但防不住有心作弊的人。
