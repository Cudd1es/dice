# Dicide quick start

[简体中文](quick-start.zh-CN.md) · [Full user guide](user-guide.md)

Five minutes from install to your first roll.

## 1. Install

Dicide is in beta, through TestFlight.

1. Open the invitation email or link, install **TestFlight** from the App Store, and accept the invite.
2. Install **Dicide** from TestFlight.
3. When TestFlight shows a new build, update. Everyone in your group needs to be on a recent version to read each other's rolls.

## 2. Roll in the app (at the table)

1. Open Dicide.
2. Pick a die (d4–d100), then set **Dice** (how many) and **Modifier**.
3. Tap **Roll**. The result shows large at the top, and the roll is added to **Recent**.

## 3. Roll in Messages (online games)

1. Open a conversation in Messages.
2. Tap **+** next to the text field and choose **Dicide**. If you don't see it, scroll the list or tap **More**.
3. Set your dice and tap **Roll**. The roll goes into the text field as a draft that shows only the formula.
4. Send it. The bubble then shows the result to everyone in the chat.

Nobody, including you, can see the result before it is sent, so there are no rerolls.

## 4. A few things to try

| Try | How |
|---|---|
| Ability check against a DC | Main die d20, set the modifier, turn on **DC** and tap the number to type it |
| Advantage / disadvantage | Main die 1d20, pick **Advantage** or **Disadvantage** |
| Bless (+1d4) | Tap **+ Bonus** → **Bless** |
| Bane (−1d4) | Tap **+ Bonus** → **Bane** |
| Damage `1d8+2d6+3` | Main die d8, modifier +3, then **+ Bonus** → d6, twice |
| Divine Smite on a longsword hit | Main die d8, modifier, then **+ Bonus** → **Divine Smite** (+2d8) |
| Say what it's for | Type in the purpose field at the top, e.g. "Perception: anyone behind the door?" |

Every control is described in the [user guide](user-guide.md).
